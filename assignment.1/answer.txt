Q1: stylesheet href on index.html
Answer: styles.css
This page is index.html, located in session6/assiment1/, same folder as styles.css.

Q2: stylesheet href on pages/courses.html
Answer: ../styles.css
This page is pages/courses.html, located one folder deeper than styles.css,
so ../ goes up to assiment1/ where styles.css lives.

Q3: Selector that styles a full course's status
Answer: .course-card[data-status="full"] .status

Explanation: This matches any element with class "status" that is a
descendant of an element with class "course-card" AND a data-status
attribute whose value is exactly "full". It does NOT match the article
itself, the h2, or the p — only the span.status inside a full card.

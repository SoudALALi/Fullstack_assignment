التجربة 1 - الخصوصية (Specificity)
  التوقع: توقعت أن يكون لون عنوان h1 باللون البنفسجي (Purple).
  الملاحظة: لون العنوان h1 ظهر باللون البنفسجي فعلاً.
  القاعدة الفائزة: #course-title
  لماذا خسرت قاعدة h1 رغم أنها مكتوبة أخيراً؟ لأن الخصوصية (Specificity) تتغلب على الترتيب. الـ ID Selector (#course-title) لديه أولوية (وزن) أعلى بكثير من الـ Element Selector (h1). المتصفح يختار دائماً القاعدة الأقوى في الخصوصية بغض النظر عن مكانها في ملف CSS.

التجربة 2 - ترتيب المصدر (Source Order)
  عندما كانت قاعدة Orange في النهاية: أصبح لون العنوان برتقالي (Orange).
  عندما نقلت قاعدة Orange قبل القاعدة الخضراء: أصبح لون العنوان أخضر (Green).
  الاستنتاج: عندما تتساوى قاعدتان في الخصوصية (كلاهما كلاس .title)، يلجأ المتصفح إلى ترتيب المصدر (Source Order). القاعدة المكتوبة في الأسفل (الأحدث) هي التي تفوز. عندما كانت البرتقالية في النهاية فازت، وعندما رفعتها للأعلى، أصبحت الخضراء هي الأخيرة ففازت.

التجربة 3 - الوراثة (Inheritance)
  قبل التعديل: كانت الفقرتان بلون رمادي غامق (#374151) لأنهما ورثتا اللون من العنصر الأب (البطاقة .course-card).
  القاعدة المستخدمة: .course-card > p { color: teal; }
  بعد التعديل: أصبحت الفقرة التعريفية (الأولى) بلون Teal، بينما بقيت فقرة الموعد داخل .details باللون الرمادي الغامق (وراثة من البطاقة).
  لماذا اخترت > (Child) بدلاً من المسافة (Descendant)؟ لأن علامة الأكبر (>) تستهدف فقط الأبناء المباشرين للبطاقة، مما يطبق اللون على الفقرة الأولى فقط. أما المسافة (المسافة الفارغة) فتستهدف كل الفقرات داخل البطاقة، بما في ذلك فقرة الموعد، وهذا سيحطم شرط أن ترث فقرة الموعد لون البطاقة.

اختبار الرابط (Link test)
  عند مرور الماوس (Hover): عندما وضعت الماوس على رابط "View topics"، تغير لونه إلى البنفسجي (#6845a8).
  عند استخدام Tab (Focus): عندما أبعدت الماوس وضغطت على زر Tab للوصول للرابط، ظهر إطار برتقالي متصل بسماكة 3px حول الرابط، بفضل :focus-visible.





  Experiment 1 - Specificity
  Prediction: I predicted the h1 text color would be Purple.
  Observed: The h1 text color is Purple.
  Winning rule: #course-title
  Why h1 loses: Even though the 'h1' rule is written last in the CSS file, it loses because of Specificity. An ID selector (#course-title) has a much higher specificity score than a type selector (h1). The browser always prioritizes the rule with the highest specificity, regardless of the source order.

Experiment 2 - Source order
  Orange at end: The color of the heading becomes Orange.
  Orange before green: The color of the heading becomes Green.
  Conclusion: When two rules have the exact same specificity (both are .title classes), the browser uses Source Order to decide. The rule that is written LAST in the CSS file will win. When orange was at the end, it won. When I moved it before green, green became the last rule and won.

Experiment 3 - Inheritance
  Before: Both paragraphs had a dark gray color (#374151) because they inherited the color from their parent, the .course-card article.
  Rule used: .course-card > p { color: teal; }
  After: The introductory paragraph became Teal, while the schedule paragraph inside .details remained dark gray (#374151).
  Why > not space: We used the Child Combinator (>), which only targets the direct child paragraph. If we used the Descendant Combinator (a space like .course-card p), it would have targeted ALL paragraphs inside the card, including the one inside the .details div, which would break the rule requiring the schedule paragraph to stay inherited.

Link test
  Hover: When I moved the mouse over the "View topics" link, its color changed to purple (#6845a8).
  Tab: When I moved the mouse away and pressed the Tab key to reach the link, a 3px solid orange outline appeared around it, thanks to the :focus-visible pseudo-class.
